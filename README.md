# 几何实验室 · AI 交互课件

系统整理了中考压轴几何模型的全部方法，覆盖全等、相似、圆的综合应用、圆中模型与最值五大专题，共131个细分章节。通过可交互课件，让学生在预测、构造、操作与验证中理解解题方法。适合初中数学课堂投屏、自主探究和课后复习。

## 地理实验室：10 个高中核心实验

[在线打开地理实验室](https://xuxufei12.github.io/ai-geometry-courseware/geography.html)。三维场景、参数操作和同步图表共同呈现地理过程；每课包含预测、两项探究任务、对照条件、观察记录、原理解释与迁移题。记录与文字解释保存在本地浏览器，可导出 CSV。

| 实验 | 可以亲手改变与观察的内容 |
| --- | --- |
| 热力环流与海陆风 | 改变时刻和海陆热力差异，观察环流反转或停止 |
| 公转与太阳直射点 | 改变日期、纬度、地轴倾角，联动公转位置、直射纬度与日照 |
| 晨昏线与昼夜长短 | 比较不同纬度、季节的昼长，推进太阳时追踪观察点 |
| 太阳高度与建筑采光 | 改变楼高、间距与季节，比较影长和后楼底部采光 |
| 冷暖锋与天气变化 | 推进锋面经过固定测站，改变水汽条件，观察气温与降水位置 |
| 三圈环流与气压带风带 | 对比单圈、三圈理想模型，观察季节偏移 |
| 水循环与城市内涝 | 比较硬化率、雨量、海绵设施对下渗、径流和积水的影响 |
| 河流侵蚀与堆积 | 改变流量、坡度、来沙及过程阶段，观察河道与沉积体 |
| 农业区位选择 | 点击六块土地，选择作物，比较热量、水分与地形的限制 |
| 流域协作与调配 | 调整入流、下泄与农业取水，在库存、农业和生态之间权衡 |

**使用：**直接打开 `docs/geography.html`；页面已内嵌三维引擎、地球纹理和样式，无 CDN、后端或外部运行时请求。三维显示需要 WebGL 2；不支持时仍可操作参数、图表与记录。支持鼠标、触屏、键盘参数输入、三种预设视角和全屏。所有过程由学生主动播放，切换课程或离开页面时暂停。

**模型边界：**太阳高度、昼长和影长使用球面几何近似；其他模型用于定性或半定量的因果比较。海陆温度、气压带位移、气团状态、输沙指数、作物评分及水量目标均明确标为教学设定。水循环、流域调度满足各自简化假设下的水量平衡，不是气象、水文、农艺或建筑工程预测工具。每课的“这个模型怎样简化了真实世界？”提供具体范围。

**课程依据：**参考[高中地理课程标准日常修订版（2017年版2025年修订）](https://www.scmlzx.net/uploadfile/2025/1110/%EF%BC%887%EF%BC%89%E6%99%AE%E9%80%9A%E9%AB%98%E4%B8%AD%E5%9C%B0%E7%90%86%E8%AF%BE%E7%A8%8B%E6%A0%87%E5%87%86%E6%97%A5%E5%B8%B8%E4%BF%AE%E8%AE%A2%E7%89%88%EF%BC%882017%E5%B9%B4%E7%89%882025%E5%B9%B4%E4%BF%AE%E8%AE%A2%EF%BC%89.pdf)和[中图版选择性必修1目录](https://www.ditu.cn/dtkczy/dtsdili/202302/22/1562676311596888348.html)等教材共同核心内容。课件文字、模型、任务均独立编写，非教材出版社官方产品。

**维护：**源码在 `src/geography/`，模型函数与场景、课程数据、界面相互分离。运行 `npm run build:geography` 单独构建，或 `npm run build` 构建全部课程。`npm test` 包含数值不变量测试；`npm run test:geography:browser` 使用本机 Chrome 检查十课操作、对照、记录持久化、导出、手机布局、离线请求与 WebGL 降级。截图输出到被 Git 忽略的 `.geography-qa/`。

## 完整示范与亲手作图

六个完整例题和131章均采用“先看完整动态图 → 关闭示范亲手作图 → 改变参数验证 → 解释方法”的流程。

- 每次进入例题或章节，先显示包含辅助点、辅助线与关键结构的完整动态图。拖动蓝色动点或输入参数，即可观察条件保持不变时的变化。
- 点击“关闭示意图，自己动手”，当前题目的示范构造会隐藏，只保留已知条件和自己已经完成的步骤。随时重新打开示范对照，操作进度保留，观看示范不计入完成度。
- [131章](https://xuxufei12.github.io/ai-geometry-courseware/chapters.html)在各章自己的画板内配置作图任务。69个模型实现族按方法配置连接、中点、延长截取、垂线、平行线、交点、旋转缩放、轴对称、平移、复制角和作圆等操作。多个章节可共用同一基础模型，具体例题及应用说明仍按章保留。
- [六个完整例题](https://xuxufei12.github.io/ai-geometry-courseware/construction.html#median)保留逐步理由、纸上作法与换图练习。旧的例题链接自动进入完整动态图，原有数据实验可从课堂返回。
- 错误的点序、角度、方向或比值不会通过。完成自己的构造后，还需预测、记录不同位置并解释。测量不能代替证明。
- 工具依据选定的几何约束准确生成点和线，支持鼠标、触屏与键盘；角度和比例支持分数、根式。这些操作不是自由笔迹识别，也不冒充完整的传统尺规模拟器。
- 学习记录仅保存在当前浏览器，不上传。关闭示范不会清空记录，“重新探究”才会重置当前章。

## 内容

新增 [131 个细分章节的方法实验](https://xuxufei12.github.io/ai-geometry-courseware/chapters.html)：全等31章、相似29章、圆综合9章、圆中模型23章、最值39章。每章包含例题、对应方法、完整动态示范、章内作图、参数控制、预测题、数据记录与解释。可按专题筛选、搜索方法，并保存本地学习进度。

这些画板研究解题方法的核心结构；部分综合题只动态呈现其中的关键步骤，不等同于复现原题全部小问。每章明确标示操作范围，原题特殊数值与方法实验参数分开陈述。[完整章节对应表](CHAPTER_COVERAGE.md)列出来源段落和方法。

另保留以下6个完整例题实验：

| 专题 | 实验 | 可操作内容 |
| --- | --- | --- |
| 全等三角形模型综合 | 把中线延长一倍 | 固定两边改变夹角；旋转三角形验证全等；探索中线范围 |
| 相似三角形综合 | 三角形里装一个矩形 | 改变矩形高度；比较宽和面积；区分正方形与最大面积 |
| 圆的综合训练 | 转动半圆，重叠会变吗 | 转动半圆；识别等边三角形；用扇形分解阴影 |
| 圆的常考模型归纳 | 割线转了，什么没变 | 转动割线；测量两段长度及乘积；用圆幂求半径 |
| 八类最值问题汇总 | 把折线路径变直 | 分别移动两个点；反射路径；验证共线与垂直条件 |
| 起步实验 | 圆中的最短距离 | 改变弦位置；测量 OC；完成最小值证明 |

每个专题有预测题、动态测量、最多八组记录、分步证明、迁移题。证明默认在作出预测并记录三个不同位置后开放；提供教师直接讲解入口。测量值是近似值，不能替代证明。

## 使用

- GitHub Pages：发布 `docs/` 目录，使用 `main` 分支。
- 离线：下载整个仓库，直接打开 `docs/index.html` 或 `docs/chapters.html`。保留整个 `docs/` 目录，包括例题公式图片所在的 `source-assets/`。
- 全部依赖和公式字体内嵌，无 CDN、登录、后端或数据上传。
- 完整例题和章节方法实验都可拖动蓝色动点，也可通过滑杆或表达式改变约束参数。触屏和键盘均可操作。
- 所有参数滑杆旁均可直接输入数值或表达式，如 `1/3`、`√2`、`2√3`、`sqrt(2)`、`π`、`(1+√5)/2`，按回车或点“应用”生效。角度默认以度为单位，也可输入 `π/6 rad`（30°）。输入框显示允许范围，错误或越界输入不会改变图形。
- 根式和分数按表达式计算后参与绘图，不先按显示的小数位舍入；计算采用浏览器浮点精度，不是符号代数运算。无穷大不是有效的几何参数。
- 完成迁移练习的标记仅保存在当前浏览器本地。

## 方法体系

围绕五大专题，系统梳理基础模型、典型题型与解题方法，将辅助线构造、全等与相似、旋转与对称、圆的性质及几何最值等方法串联成完整的学习体系。每章结合例题与动态实验，帮助学生理解方法的适用条件、关键步骤和迁移应用。

## 修改与构建

源码位于 `src/`，独立网页输出到 `dist/`。安装 Node.js 后运行：

```sh
npm install
npm run build
```
