# 几何实验室 · AI 交互课件

让学生操作、预测、验证，最终用几何推理解释结论。适合初中数学课堂投屏、自主探究和课后复习。

[在线打开几何实验室](https://xuxufei12.github.io/ai-geometry-courseware/)

## 内容

| 专题 | 实验 | 可操作内容 |
| --- | --- | --- |
| 全等三角形模型综合 | 把中线延长一倍 | 固定两边改变夹角；旋转三角形验证全等；探索中线范围 |
| 相似三角形综合 | 三角形里装一个矩形 | 改变矩形高度；比较宽和面积；区分正方形与最大面积 |
| 圆的综合训练 | 转动半圆，重叠会变吗 | 转动半圆；识别等边三角形；用扇形分解阴影 |
| 圆的常考模型归纳 | 割线转了，什么没变 | 转动割线；测量两段长度及乘积；用圆幂求半径 |
| 八类最值问题汇总 | 把折线路径变直 | 分别移动两个点；反射路径；验证共线与垂直条件 |
| 起步实验 | 圆中的最短距离 | 改变弦位置；测量 OC；完成最小值证明 |

每个专题有预测题、动态测量、最多八组记录、分步证明、迁移题。证明默认在作出预测并记录三个不同位置后开放；提供教师直接讲解入口。测量值是近似值，不能替代证明。

## 使用

- GitHub Pages：发布 `docs/` 目录，使用 `main` 分支。
- 离线：下载仓库，直接打开 `docs/index.html`。保留同目录的 `circle-distance.html` 和 `LICENSE`。
- 全部依赖和公式字体内嵌，无 CDN、登录、后端或数据上传。
- 触屏可拖动蓝色手柄；键盘用户可用滑块、按钮和方向键操作。
- 完成迁移练习的标记仅保存在当前浏览器本地。

## 选题说明

来自用户提供的《26届中考压轴题模型+方法（几何）》，按五个一级专题各取一个例子。具体定位、动态改编范围与修正见 [选题与数学核验](SOURCE_NOTES.md)。原始 Word 文档不包含在仓库中。

## 修改与构建

源码位于 `src/`，独立网页输出到 `dist/`。安装 Node.js 后运行：

```sh
npm install
npm run build
```

构建时保留 `dist/circle-distance.html`，其内嵌的公式字体用于新页面。构建脚本自动将部署内容从 `dist/` 同步到 `docs/`，推送到 `main` 后由 GitHub Pages 自动更新。第三方 KaTeX 保留其 MIT 许可，见 [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES)。
